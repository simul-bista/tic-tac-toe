# Tic-Tac-Toe 1.0.0

**Status: UNRELEASED — release candidate**

## Included

- Human-versus-human Tic-Tac-Toe on a 3×3 board.
- Alternating X/O turns with validation for occupied and out-of-range moves.
- Winner and draw detection with terminal-game move rejection.
- Numbered command-line input (positions 1–9), board rendering, and win/draw announcements.
- Clean cancellation on end-of-file or Ctrl+C.

## Deferred

The computer opponent, difficulty levels, score tracking, and save/load remain future features and are not part of this release candidate.

## Release status

These notes describe an unreleased candidate. No release date or published release is claimed.
