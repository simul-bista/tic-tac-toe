# Tic-Tac-Toe

A simple command-line Tic-Tac-Toe game written in Python.

## Goal

Build a clean and well-tested implementation of Tic-Tac-Toe while learning GitHub Copilot's:

- Agent workflows
- Planning capabilities
- Code reviews
- Test generation
- Documentation generation

## Requirements

### Gameplay

- Two players (X and O)
- 3x3 board
- Alternate turns
- Detect winner
- Detect draw
- Prevent invalid moves

### Future Features

- Computer opponent
- Difficulty levels
- Score tracking
- Save/load game
